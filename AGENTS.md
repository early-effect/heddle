# AGENTS.md

Guidance for agents working in **heddle** (`early-effect/heddle`). Scala 3 / ZIO 2 HTTP library. Published to Maven Central as `rocks.earlyeffect::heddle`, `rocks.earlyeffect::heddle-brotli`, `rocks.earlyeffect::heddle-oauth`, and `rocks.earlyeffect::heddle-mcp`.

## Layout

| Path | Role |
| --- | --- |
| [`heddle/`](heddle/) | Published core. ZIO + zio-json. JVM / Loom. |
| [`brotli/`](brotli/) | Published `heddle-brotli`. RFC 7932 `br`, no JNI. |
| [`oauth/`](oauth/) | Published `heddle-oauth`. JOSE, resource server, OAuth client, OIDC provider. |
| [`mcp/`](mcp/) | Published `heddle-mcp`. MCP 2026-07-28 server (HTTP + stdio) over `Api` / `BoundOp`. HTTP and stdio also answer 2025-11-25 `initialize`. |
| [`example/`](example/) | Runnable users API + embedded OP + Swagger UI + MCP. `publish / skip`. |
| [`docs/`](docs/) | Specular DocSpecs + `BuildSite`. `publish / skip`. |
| [`docs-js/`](docs-js/) | Scala.js client for `exampleDom` widgets. |
| [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | Generated by zipx. Do not hand-edit. |

Root aggregates `heddle`, `brotli`, `oauth`, `mcp`, `example`, `bench`, `docs`, and `docsJS` and skips its own `publish` / `test`.

Core packages under `heddle/src/main/scala/heddle/`:

| Path | Role |
| --- | --- |
| `exports.scala` | Curated `import heddle.*` facade. Datastar is not on it. |
| `http/` | Request, Response, Body, Method, Status, HttpVersion, Url, Path, QueryParams, MediaType, encodings |
| `http/header/` | HeaderName, Header, Headers, TypedHeader, Cookie, Auth, Host, dates |
| `route/` | Handler, Route, Routes, Middleware, PathCodec, PathDsl, QueryCodec, HeaderCodec. Path macros stay here. |
| `endpoint/` | Endpoint, BoundOp, Api, Schema, OpenApi, OpArgs |
| `Server.scala` | `package heddle` (ZIO Tag). Do not `export Server`. |
| `server/` | Tls, Files, Compressor, Http2Config, HeddleApp |
| `client/` | Client |
| `error/` | HeddleError, HttpError, ServerError |
| `auth/` | Basic, Bearer, API key extractors. JWT lives in `heddle-oauth`. |
| `sse/` `ws/` `datastar/` | Public subpackages. Datastar `readSignals` is an extension on Request, not a Request method. |
| `internal/` | Ascii, ConnBuf, Nio, Http1, OpenAPI printer |
| `internal/h2/` | HTTP/2 engine (`private[heddle]`) |

User JSON is `zio.json.JsonCodec` (`import heddle.*` re-exports it). `derives Schema, JsonCodec` on domain types. Schema (OpenAPI shapes) lives in core.

## Commands

sbt 2: `test` is `testQuick` and can skip. Use **`testFull`** for proof. Prefer Metals `compile-file` then Metals `test` while iterating. Join Metals' BSP with `sbt --no-server`; do not spawn a second `--detach-stdio` server.

```bash
sbt compile
sbt testFull
sbt "heddle/testFull"
sbt "brotli/testFull"
sbt "oauth/testFull"
sbt "mcp/testFull"
sbt "docs/testFull"
sbt docs/specularSite
sbt --no-server ~docs/specularPreview
sbt "oauth/run"
sbt "example/run"
sbt zipxWorkflowGenerate
```

## CI and publishing

zipx Aggregate: parallel `fmt` / `workflow-check` / `advisories` / `test` (`testFull` plus `docs/specularSite`), then tag-gated `ZipxCentral.release` and `ZipxDocs.pages`. Fork-gated to `early-effect/heddle`.

Capability or graph change → `sbt zipxWorkflowGenerate` and commit `.github/workflows/ci.yml` plus `.github/actions/zipx-sbt-setup/`. CI fails on drift via `zipxWorkflowCheck`.

Publishing is CI-only (`usePgpKeyHex` from `PGP_KEY_HEX`; sentinel `MISSING_KEY_HEX` locally). Do not cut tags or push `main` from an agent unless asked.

## Conventions

- Scala 3 only: `enum`, `given`, `derives`, inline, optional braces. Scalafmt: max 120, `align.preset = more`.
- `-Wunused:all`: no unused imports or locals.
- Handler is `Request => ZIO[R, E, Response]`. Middleware is `Routes => Routes` via `@@`.
- Tests: ZIO Test `ZIOSpecDefault`. JSON tests use `zio.json.JsonCodec`.
- Keep [`example/`](example/) building when you change the public API.
- No AI attribution in commits or PR text.
